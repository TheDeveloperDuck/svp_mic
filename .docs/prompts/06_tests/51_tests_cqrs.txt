  plan appears with correct rep_id, status "draft", visit_count 0,

  assert visit_count is 1 for that plan

- after creating an expense, GET /api/expenses/read/history and
  assert the expense appears with status "submitted"

- after approving an expense, GET /api/expenses/read/history and
  assert status is "approved" and decided_at is not null for that
  expense

- GET /api/expenses/read/rep/{rep_id} returns only expenses for
  that rep
