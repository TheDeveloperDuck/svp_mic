tests/functional/e2e/test_full_lifecycle.py:

helpers to define at the top of the file:
_create_user(client, suffix, role="sales_rep", tag="a") — POST /api/users,
  name="User {tag} {suffix}", email="{tag}{suffix}@example.com",
  password="pass", role=role. return response json.
_create_customer(client, suffix) — POST /api/customers,
  name="Customer {suffix}", address="Address {suffix}". return json.
_create_plan(client, rep_id, suffix) — POST /api/plans,
  rep_id=rep_id, date="2025-06-01",
  start_location="Start {suffix}", end_location="End {suffix}". return json.
_add_visit(client, plan_id, customer_id, customer_name, order=1) —
  POST /api/plans/{plan_id}/visits,
  body: plan_id=plan_id, customer_id=customer_id,
  customer_name=customer_name, scheduled_order=order. return json.
_add_call(client, plan_id, customer_id, customer_name, order=1) —
  POST /api/plans/{plan_id}/calls,
  body: plan_id=plan_id, customer_id=customer_id,
  customer_name=customer_name, scheduled_order=order. return json.
_confirm_plan(client, plan_id) — PATCH /api/plans/{plan_id}/confirm. return response.
_activate_plan(client, plan_id) — PATCH /api/plans/{plan_id}/activate. return response.
_complete_plan(client, plan_id) — PATCH /api/plans/{plan_id}/complete. return response.
_create_expense(client, rep_id, plan_id, suffix) — POST /api/expenses,
  rep_id=rep_id, plan_id=plan_id, category="fuel",
  amount=50.00, description="Expense {suffix}". return json.
_submit_expense(client, expense_id) — PATCH /api/expenses/{expense_id}/submit. return response.
_approve_expense(client, expense_id, manager_id) —
  PATCH /api/expenses/{expense_id}/approve, json={"manager_id": manager_id}. return response.
_reject_expense(client, expense_id, manager_id) —
  PATCH /api/expenses/{expense_id}/reject, json={"manager_id": manager_id}. return response.

====

general standards:
all tests are async def with @pytest.mark.anyio.
concurrent operations use asyncio.gather.
use unique_suffix per test to avoid collisions — append str(i) for indexed items.
no sleeps except polling loops with explicit max retries.
polling loops: max 10 retries, 1 second sleep between retries, use asyncio.sleep.
each test is fully independent and creates its own data.
plan_id must be included in the request body for all visit and call POST requests.
expense category must be "fuel" not "travel".
PATCH visits to "completed" must include outcome_notes in the body.
