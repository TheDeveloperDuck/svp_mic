tests/functional/unit/test_tracing_unit.py:
read shared/tracing.py before writing any tests.
import extract_tracing_headers and build_tracing_headers from shared.tracing.
create a fake Request helper using a simple class or dataclass with a headers dict.

test_extract_returns_only_present_headers:
build a request with only x-b3-traceid and x-request-id set.
assert the result contains exactly those two keys.

test_extract_skips_absent_headers:
build a request with only x-b3-traceid set.
assert x-b3-spanid is not in the result.

test_extract_empty_when_no_tracing_headers:
build a request with no tracing headers.
assert result is an empty dict.

test_extract_all_seven_headers:
build a request with all seven headers set.
assert all seven keys are present in the result.

test_build_returns_same_as_extract:
build a request with three headers set.
assert build_tracing_headers returns the same dict as extract_tracing_headers for the same request.

test_build_empty_when_no_headers:
assert build_tracing_headers returns empty dict for a request with no tracing headers.

test_build_returns_only_present:
build a request with two of the seven headers.
assert result has exactly two keys.

test_neither_raises_with_no_headers:
call both functions on a request with an empty headers dict.
assert neither raises.
