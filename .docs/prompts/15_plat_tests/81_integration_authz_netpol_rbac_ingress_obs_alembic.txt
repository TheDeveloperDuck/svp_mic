RBAC, ingress routing, observability, and Alembic migrations.

Jaeger port-forwarded on 16686.
all async tests use pytest with anyio.
do not touch anything outside tests/functional/.

tests/functional/integration/test_observability.py:
uses httpx directly (not the client fixture) for Prometheus and Jaeger calls.
Prometheus is at http://localhost:9090.
Jaeger is at http://localhost:16686.

define a module-scoped async fixture named generate_load that:
  creates an httpx.AsyncClient pointed at http://localhost:8080.
  sends 10 GET /api/customers requests before yielding.
  closes the client after yielding.
  mark with @pytest.fixture(scope="module").

all tests in this file are async and use @pytest.mark.anyio.

test_prometheus_returns_istio_requests_total:
  async with httpx.AsyncClient() as c:
    GET http://localhost:9090/api/v1/query
      with params {"query": "istio_requests_total"}
  assert status 200.
  data = response.json()
  assert data["status"] == "success".
  assert len(data["data"]["result"]) > 0.

test_prometheus_has_customer_user_service_metrics:
  query istio_requests_total{destination_service_name="customer-user-service"}.
  assert at least one result.

test_prometheus_has_planning_service_metrics:
  same for destination_service_name="planning-service".

test_prometheus_has_expense_service_metrics:
  same for destination_service_name="expense-service".

test_jaeger_returns_services:
  async with httpx.AsyncClient() as c:
    GET http://localhost:16686/api/services
  assert status 200.
  assert len(response.json()["data"]) > 0.

test_jaeger_has_traces_after_load:
  GET http://localhost:16686/api/traces
    with params {"service": "istio-ingressgateway", "limit": "5"}
  assert status 200.
  assert len(response.json()["data"]) > 0.

test_jaeger_trace_contains_multiple_spans:
  GET http://localhost:16686/api/traces
    with params {"service": "istio-ingressgateway", "limit": "1"}
  parse first trace.
  assert len(trace["spans"]) > 1.

test_prometheus_rate_limit_returns_429:
  apply k8s/istio/testing/rate-limit.yaml via subprocess kubectl apply.
  sleep 2 seconds.
  send 25 concurrent GET /api/customers requests using asyncio.gather
    with httpx.AsyncClient at http://localhost:8080.
  status_codes = [r.status_code for r in responses].
  assert 429 in status_codes.
  subprocess kubectl delete -f k8s/istio/testing/rate-limit.yaml to restore.
  sleep 2 seconds.

tests/functional/integration/test_alembic_migrations.py:
all tests use subprocess and are plain def.

test_customer_user_service_init_container_exited_zero:
  kubectl get pod -n svp -l app=customer-user-service -o json.
  parse JSON.
  find initContainerStatuses list.
  find the container whose name contains "migrate" or "alembic" or "init".
  assert containerStatus["state"]["terminated"]["exitCode"] == 0.

test_planning_service_init_container_exited_zero:
  same for label app=planning-service.

test_expense_service_init_container_exited_zero:
  same for label app=expense-service.

test_customer_user_db_migration_idempotent:
  get pod name: kubectl get pod -n svp -l app=customer-user-service
    -o jsonpath='{.items[0].metadata.name}'
  kubectl exec -n svp {pod} -c customer-user-service --
    alembic -c customer_user_service/alembic.ini upgrade head
  assert return code 0.

test_planning_db_migration_idempotent:
  same for planning-service using planning_service/alembic.ini.

test_expense_db_migration_idempotent:
  same for expense-service using expense_service/alembic.ini.

test_all_three_services_running_after_migrations:
  kubectl get pods -n svp -o json.
  for pods matching customer-user-service, planning-service, expense-service
    assert status.phase == "Running".

====

general standards:
all async tests use @pytest.mark.anyio.
synchronous kubectl tests are plain def with no async decorator.
subprocess calls use capture_output=True, text=True, timeout=60.
no mocking.
each test is independent.
the debug_pod fixture is defined once per file that needs it
  (both test_authorization_policy.py and test_network_policy_enforcement.py).
