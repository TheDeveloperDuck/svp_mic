update docker-compose.yml at the project root.

add the following services alongside the existing customer_user_service and postgres:

zookeeper:
- image: confluentinc/cp-zookeeper:7.6.0
- internal port 2181
- no need to expose externally
- set ZOOKEEPER_CLIENT_PORT and ZOOKEEPER_TICK_TIME environment variables

kafka:
- image: confluentinc/cp-kafka:7.6.0
- depends on zookeeper being healthy
- internal port 9092, no need to expose externally
- set the following environment variables:
  KAFKA_BROKER_ID: 1
  KAFKA_ZOOKEEPER_CONNECT: zookeeper:2181
  KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
  KAFKA_OFFSETS_TOPIC_REPLICATION_FACTOR: 1
- healthcheck using kafka-broker-api-versions

redis:
- image: redis:7.2-alpine
- internal port 6379, no need to expose externally
- healthcheck using redis-cli ping

update customer_user_service:
- add kafka and redis to depends_on
- all three dependencies must be healthy before the service starts

update .env.example:
- add REDIS_URL=redis://redis:6379/0

do not change anything else.
