create the saga orchestration for the planning_service.

files:
- planning_service/saga/__init__.py
- planning_service/saga/orchestrator.py
- planning_service/consumers/__init__.py
- planning_service/consumers/customer_events.py

__init__.py files:
empty package markers with module docstrings.

orchestrator.py:
async function confirm_plan(plan_id: UUID, db: AsyncSession) -> None.
within a single db transaction:
- change the plan status from draft to confirmed.
- write a plan.confirmed event to the outbox table.
- payload must include plan_id and the list of customer_ids from visits and calls on that plan.
if either the plan update or the outbox write fails, roll back both.
raise PlanConfirmationError from shared/exceptions.py on failure.
log using shared logger.

customer_events.py:
aiokafka consumer listening on the customer.deactivated topic.
consumer group id: planning_service.
when a customer.deactivated event is received:
- query all confirmed or active plans that contain that customer_id in visits or calls.
- for each affected plan, roll back plan status to draft.
- write a plan.rolled_back event to the outbox within the same transaction.
handle asyncio.CancelledError cleanly on shutdown.
log using shared logger.
run as async function run_customer_events_consumer().

after creating the files update planning_service/main.py to start
run_customer_events_consumer as a background task in the lifespan startup block.

follow pep8 at .claude/pep8_python.md.
follow pep257 at .claude/pep257_python_docstring.md.
