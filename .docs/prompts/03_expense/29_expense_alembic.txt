set up alembic for expense_service.

files:
- expense_service/alembic.ini
- expense_service/alembic/env.py
- expense_service/alembic/versions/ (empty directory, add .gitkeep)

alembic.ini:
standard alembic config.
set script_location to alembic.
database url left as a placeholder, it will be overridden in env.py from the .env file.

env.py:
use async sqlalchemy engine to match the rest of the service.
read the database url from the .env file using python-dotenv.
read from EXPENSE_DATABASE_URL.
import the base metadata from expense_service/models.py so alembic
can detect the models and generate migrations automatically.
configure for online mode only, offline mode is not needed.

after creating the files, generate the initial migration inside the container.
the expense_service container must be running before this step.
run the following command to generate the migration:
    docker exec expense_service alembic -c expense_service/alembic.ini revision --autogenerate -m "initial schema"
then apply it:
    docker exec expense_service alembic -c expense_service/alembic.ini upgrade head

if the container is not yet running, skip the migration generation step and note that
it must be run manually once the container is up.

follow pep8 at .claude/pep8_python.md.
follow pep257 at .claude/pep257_python_docstring.md.
