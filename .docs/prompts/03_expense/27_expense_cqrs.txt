expense_projection.py:
async function update_expense_projection(expense_id: UUID, db: AsyncSession) -> None.
reads the current state of an expense_submission by expense_id.
upserts a row in the expense_read_model table with:
- rep_id, plan_id, category, amount, status, submitted_at from the expense_submission row.
- decided_at from the expense_submission row.
- updated_at set to datetime.now(UTC).
if the expense does not exist log a warning and return.
log using shared logger.

expenses_read.py:
fastapi router with prefix /expenses/read.
read-only endpoints using expense_read_model table only.
- GET /expenses/read/rep/{rep_id} — all expense summaries for a rep.
- GET /expenses/read/status/{status} — all expenses filtered by status string.
- GET /expenses/read/history — full history, optional query params rep_id and status.
return ExpenseReadModelResponse schema.
use get_db from expense_service/database.py.
log using shared logger.

after creating the files register the expenses_read router in expense_service/main.py.
